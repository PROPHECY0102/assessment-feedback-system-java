### To Build and Run AFS via NetBeans

1. Open the project on NetBeans
2. Click Clean and Build Project
3. Click Run Project

### To Build and Run AFS via Command Line Interface (CLI) or VSCode

1. Open the CMD/Bash/Terminal on the project root directory
2. Copy and run the mvn command below

```sh
# Run Maven clean, compile, and execute
mvn clean compile exec:java -Dexec.mainClass="com.apu_afs.Main" -e
```
